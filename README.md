# Chapa Games – Loja Virtual de Jogos

## Objetivo
Desenvolver uma loja virtual de jogos que permita aos clientes consultar os produtos disponíveis, adicionar jogos ao carrinho, visualizar o valor total da compra e registrar pedidos. O sistema também deverá oferecer recursos básicos para que administradores gerenciem o catálogo.

## Problema
A ausência de uma plataforma centralizada para consulta e comercialização de jogos dificulta a organização das informações dos produtos, como nomes e preços. Os clientes precisam de um ambiente simples para organizar suas compras, enquanto os administradores necessitam de uma forma prática de gerenciar os jogos e os pedidos.

## Usuários
- **Clientes:** consultam jogos, adicionam produtos ao carrinho e realizam pedidos.
- **Administradores:** cadastram, consultam e gerenciam os jogos e os pedidos.
- **Equipe de desenvolvimento:** desenvolve, testa e mantém o sistema.

## Funcionalidades iniciais
1. Exibir o catálogo de jogos disponíveis.
2. Cadastrar jogos no catálogo.
3. Consultar informações e preços dos jogos.
4. Adicionar jogos ao carrinho.
5. Remover jogos do carrinho.
6. Calcular e apresentar o valor total da compra.
7. Finalizar a compra e registrar o pedido.

## Tecnologias

## Escopo inicial
O projeto contempla o catálogo de jogos, cadastro e consulta de produtos, gerenciamento básico do carrinho, cálculo do total e registro de pedidos.
